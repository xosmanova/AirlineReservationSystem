# SkyReserve

A modern airline reservation and flight operations management platform.

### Tech Stack
- **Backend:** C# / .NET 10, ASP.NET Core Web API, Entity Framework Core
- **Database:** Microsoft SQL Server
- **Admin Portal:** ASP.NET Core MVC
- **Client App:** Modern JavaScript, HTML5/CSS3, Web Speech API

### Project Structure
- `src/Core/` — Domain entities and application logic
- `src/Infrastructure/` — Data access, SQL Server persistence, and external services
- `src/Presentation/` — Central RESTful Web API
- `src/Admin/` — ASP.NET Core MVC management portal
- `src/Client/` — Customer web application
